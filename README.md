# Prime Advo website

Static site. Open `index.html` or upload the whole folder to any host (public_html / htdocs root).

Folder layout
- index, about, services, blog, blog-post, contact, privacy, terms, 404 (.html)
- css/style.css   all styles (mobile-first, breakpoints at 360, 700, 960 px)
- js/main.js      menu, FAQ, blog articles (POSTS object), contact form, animations
- assets/img/     logo.png, logo-light.png (footer), favicon.png, apple-touch-icon.png, og-image.png
- robots.txt, sitemap.xml

Before launch
1. Domain: pages, sitemap.xml and robots.txt use https://www.primeadvo.com. Find and replace with your real domain.
2. Contact form: sends through FormSubmit to info@primeadvo.site. The first submission triggers a one-time confirmation email to that inbox; click it once. If sending fails the visitor's email app opens instead.
3. Social icons in the footer link to "#". Put your real profile URLs there.
4. Replace the Unsplash placeholder photos with your own work (search for images.unsplash.com).
5. Testimonials on the home page and the team roles on the About page are placeholders. Confirm or replace them with real, approved content.
6. Add the founder portrait as assets/img/om-mishra.jpg (initials show until then).
7. Add the real office address and map embed on contact.html.
